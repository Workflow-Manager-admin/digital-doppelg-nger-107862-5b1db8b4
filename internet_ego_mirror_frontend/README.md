# Internet Ego Mirror – React Quiz App

A playful, modern, and minimalistic single-page React quiz that reveals your internet alter ego. Answer quirky, internet-themed questions and get a shareable persona card!

## Features

- **Fun, viral-style quiz:** 8 unique, quirky questions
- **Modern, clean UI:** Playful but minimal style with distinct accent color
- **Animated, mobile-friendly card layout**
- **Result Persona:** Name, description, fake résumé, aura badge, social recommendation, emoji
- **Shareable Result Card:** Copy persona to clipboard to share with friends
- **No extra dependencies:** Pure React and CSS

## Color Palette

- **Accent:** #23CE6B
- **Primary:** #6C63FF
- **Secondary:** #FF6584

## Screens

- **Welcome:** App title, playful icon, brief intro, prominent start button
- **Quiz:** One question per screen; large, tap-friendly answer cards; progress shown at top
- **Result:** Large persona badge, persona name, description, fun résumé, aura color visual, share/copy and restart buttons

## Usage

- `npm start` – Launch development server ([http://localhost:3000](http://localhost:3000))
- `npm run build` – Build for production
- `npm test` – Run test runner (minimal for this template)

## Customizing

See `src/App.js` for question and persona data. Change styles/theme in `src/App.css`.
